Ideas and themes

Our team generated several ideas to improve group management in the Canvas mobile application. The ideas focused on usability, functionality, and user experience, including an Add Members button, student search, notifications, full mobile group management, and real-time synchronization with the web version.

Selection

We chose the Add Members feature because it allows students to manage groups directly on mobile devices, improving convenience and efficiency.

Idea Card

One chosen idea

Add Members feature for Canvas Mobile. This feature allows students to add members to groups directly in the Canvas mobile application. It is designed for students and group leaders who manage course groups on mobile devices.

How it works

The user opens the Groups section in Canvas Mobile and taps the new Add Members button. The user can search for students and add them to a group. The application then updates the group and displays a confirmation message.

Expected benefit

Students can manage groups without switching to the web version of Canvas. This saves time, improves usability, and provides a more complete mobile experience. Further user testing is needed.
